## Usage Guidelines

1. **One color per module, always.** Don't reassign colors between modules in different contexts.
2. **Use as accents, not fills.** A small dot, border, or icon tint — not an entire card background.
3. **Maintain the dark-mode context.** These colors are calibrated for dark backgrounds. On light backgrounds, reduce opacity to ~80% or use a lighter tint.
4. **In diagrams (hexagon maps, flow charts):** Use the agent color as the fill with white text/icons inside.
5. **In navigation / tabs:** Use the agent color as an underline or left-border indicator, not as the full tab background.

## Extending the Map

If new agents or modules are added, select from the remaining functional palette:

| Available Color | Hex       | Reserved For     |
| --------------- | --------- | ---------------- |
| Yellow          | `#eab308` | Unassigned       |
| Red             | `#ef4444` | Unassigned       |

Avoid introducing entirely new hues. The existing 8-color system (6 agents + 2 reserve) covers the full spectrum without clashing.
