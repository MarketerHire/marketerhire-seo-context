# MH1HQ Brand Identity Guide

**Brand:** MH1HQ — Your AI-Native Marketing Team

This folder is the universal reference point for the MH1HQ visual identity. It applies to any format — web, video, print, presentations, social, documentation, and beyond.

---

## Quick Reference

| Element         | Value                                              |
| --------------- | -------------------------------------------------- |
| Primary Colors  | Purple `#7c3aed` / Pink `#ec4899`                  |
| Background      | Dark navy `#0a0e1a`                                |
| Primary Font    | Inter (sans-serif)                                 |
| Mono Font       | Geist Mono                                         |
| Primary Gradient| `135deg, #7c3aed → #ec4899`                        |
| Logo            | White wordmark on dark / see logo-usage.md         |
| Tagline         | `: Your AI-Native Marketing Team`                  |

## How to Use This Guide

1. **Starting a new project?** Read `04-design-principles.md` first for the overall aesthetic direction.
2. **Need specific values?** Go straight to `01-colors.md` or `02-typography.md`.
3. **Building in code?** Import or reference `07-design-tokens.css` for ready-to-use variables.
4. **Working with the logo?** See `03-logo-usage.md` for correct placement and sizing.
5. **Adding animation?** Follow `05-motion-and-animation.md` for consistent motion language.
