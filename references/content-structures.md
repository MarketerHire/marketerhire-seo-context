# Content Structure Templates

Detailed structures for each content type. Use these when creating outlines.

---

## Pillar Guide Structure (5,000-8,000 words)

The definitive resource on a topic. Aims for Featured Snippet and category authority.

### Section Breakdown

```
1. Hook Intro (150-250 words)
   - Answer the title question immediately
   - Why this matters NOW
   - Who this is for (and who it's not for)

2. Quick Answer Section (200-300 words)
   - Direct answer for Featured Snippet
   - TL;DR for skimmers
   - Key takeaway in 2-3 sentences

3. Core Sections (3-5 major sections)
   - Each 800-1,500 words
   - Each answers a major sub-question
   - H2 headers with keyword variations
   - Include:
     * Definition/explanation
     * Why it matters
     * How to do it
     * Examples
     * Common mistakes

4. Implementation / How to Apply (300-500 words)
   - Specific actionable steps
   - Decision framework if applicable
   - "Start here" recommendation

5. FAQ Section (5-10 questions)
   - From PAA research
   - Schema-ready format
   - Concise answers (50-100 words each)

6. Conclusion with CTA (150-200 words)
   - Summarize key takeaway
   - Clear next action
   - No new information
```

## How-To Tutorial Structure (2,000-3,000 words)

Step-by-step instructions for completing a specific task.

### Section Breakdown

```
1. What You'll Achieve (150-200 words)
   - End result shown first (maybe a screenshot)
   - Time estimate
   - Prerequisites/what you'll need
   - Difficulty level

2. Why This Method (200-300 words)
   - Context and alternatives
   - Why this approach works
   - When NOT to use this method

3. Step-by-Step Instructions (1,200-2,000 words)
   - Numbered steps
   - One action per step
   - Screenshots/examples inline
   - Troubleshooting tips after tricky steps
   - Expected outcomes at checkpoints

4. Variations / Advanced Tips (300-400 words)
   - Alternative approaches
   - Power user tips
   - Customization options

5. Common Mistakes (200-300 words)
   - What usually goes wrong
   - How to fix each mistake
   - Warning signs to watch for

6. Next Steps with CTA (100-150 words)
   - What to do after completing
   - Related tutorials
   - Resources for going deeper
```

## Comparison Structure (2,500-4,000 words)

X vs Y comparison for commercial intent keywords.

### Section Breakdown

```
1. Quick Verdict (200-300 words)
   - Bottom line recommendation FIRST
   - "Choose X if... Choose Y if..."
   - Clear winner statement (if applicable)

2. Comparison Table
   - 8-12 key differentiators
   - Pricing
   - Best for
   - Key features
   - Rating/score

3. Deep Dive: Option A (800-1,000 words)
   - What it is (brief)
   - Key features (3-5)
   - Pros (3-5)
   - Cons (2-3)
   - Best for (specific use cases)
   - Pricing details
   - Real example/experience

4. Deep Dive: Option B (800-1,000 words)
   - Same structure as Option A

5. Head-to-Head Comparison (300-500 words)
   - Specific scenarios
   - "If you need X, choose Y"
   - Direct feature comparisons

6. FAQ (3-5 questions)
   - Common decision questions
   - Migration questions
   - Pricing questions

7. Final Recommendation with CTA
   - Reiterate recommendation
   - Specific next step
```

## Listicle Structure (2,000-3,000 words)

Curated list of tools, tips, examples, or resources.

### Section Breakdown

```
1. Intro with Context (150-200 words)
   - Why this list matters
   - How items were selected
   - What's NOT included (and why)

2. Quick Summary Table/List
   - All items at a glance
   - Key differentiator for each
   - For skimmers who want the TL;DR

3. Individual Items (150-300 words each)
   - What it is (1 sentence)
   - Why it's included
   - Best for / Use case
   - Key features (2-3)
   - Limitations (honesty builds trust)
   - Pricing (if applicable)

4. How to Choose (200-300 words)
   - Decision framework
   - Questions to ask yourself
   - Matching needs to options

5. FAQ (3-5 questions)

6. Conclusion with CTA
   - Summary of top picks
   - Next step
```

## Universal Best Practices

### First Paragraph Rules
1. Answer the main question immediately
2. No throat-clearing or setup
3. Reader should know if they're in the right place

### Header Optimization
- H1: Primary keyword + hook
- H2: Keyword variations + clear section topics
- H3: Specific subsections (questions work well)

### Internal Linking Strategy
- Link to deeper content on subtopics
- Link from existing content to new piece
- Use descriptive anchor text

### Featured Snippet Targets
- **Definition**: 40-50 word answer in first paragraph
- **List**: H2 question + immediate numbered list
- **Table**: Use actual HTML/markdown tables
- **Steps**: H2 "How to..." + numbered steps

### Word Count Guidelines
| Type | Minimum | Target | Maximum |
|------|---------|--------|---------|
| Pillar | 5,000 | 6,500 | 8,000 |
| How-To | 2,000 | 2,500 | 3,000 |
| Comparison | 2,500 | 3,500 | 4,000 |
| Listicle | 2,000 | 2,500 | 3,000 |
