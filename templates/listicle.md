## Section Guidelines

### Intro
**Goal:** Set context and establish credibility.

**Include:**
- Why this list matters (stakes)
- How items were chosen (methodology)
- What criteria were used
- What was explicitly excluded
- Quick tease of #1 pick

**Example:**
> After testing 40+ AI writing tools over the past year across real client projects, I narrowed it down to these 10. Each tool was evaluated on output quality, speed, pricing, and ease of use. I excluded tools that require coding or only work for specific niches.
>
> Quick preview: Claude takes the top spot for long-form content, but there's a better choice if you're focused on marketing copy.

### Summary Table
**Goal:** Serve skimmers and win Featured Snippet.

**Include:**
- Rank number
- Item name
- "Best for" (one-liner)
- Price (starting price or range)

**Keep cells short** - One-liners only.

### Individual Items
**Goal:** Comprehensive mini-review of each item.

**Format for each (150-300 words):**
1. **Header:** Rank + Name + Tagline
2. **Quick facts:** Best for, Price
3. **What it is:** 1 sentence definition
4. **Why it made the list:** 2-3 sentences on standout qualities
5. **Key features:** 3 bullet points
6. **Limitations:** 1 honest drawback (builds trust)
7. **Our take:** 1-2 sentence personal opinion

**Rules:**
- Be consistent in structure across all items
- Vary the specific content (avoid repetitive phrasing)
- Include limitations for EVERY item
- Add "Our take" with personal voice

### How to Choose
**Goal:** Decision framework for different user types.

**Format:**
- "If you need X, choose Y because Z"
- Cover 4-6 different scenarios
- Include budget option
- Include "best overall" recommendation

**Common scenarios:**
- Budget-conscious
- Best overall/premium
- Specific use case 1
- Specific use case 2
- Beginners
- Power users

### FAQ
**Goal:** Capture long-tail queries.

**Include:**
- "What's the best X for Y?"
- Pricing/budget questions
- Comparison questions
- PAA questions from research

### Bottom Line
**Goal:** Clear recommendation and next step.

**Include:**
- Restate #1 pick with one reason
- Mention runner-up
- Clear CTA (try, buy, learn more)

## Item Count Guidelines

| List Type | Ideal Count | Minimum | Maximum |
|-----------|-------------|---------|---------|
| "Best" tools/products | 10 | 7 | 15 |
| Tips/strategies | 10-15 | 7 | 21 |
| Examples | 15-20 | 10 | 30 |
| Resources | 15-25 | 10 | 50 |

**Why these numbers:**
- Odd numbers feel more authentic than round numbers
- Too few = not comprehensive enough
- Too many = overwhelming

## Checklist Before Submission

```
Content Quality:
[ ] Selection methodology explained
[ ] Summary table present
[ ] Each item has consistent structure
[ ] Limitations included for each item
[ ] Personal opinion ("Our take") for each
[ ] "How to Choose" decision framework

SEO:
[ ] Number in title (e.g., "10 Best")
[ ] Primary keyword in title and H1
[ ] Table present (Featured Snippet)
[ ] FAQ section with buying questions

Voice:
[ ] Rankings feel justified
[ ] Honest about limitations
[ ] Personal experience evident
[ ] Not just feature lists - opinions included
```
