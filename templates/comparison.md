## Section Guidelines

### Quick Verdict
**Goal:** Immediate value for skimmers and Featured Snippet.

**Rules:**
- Lead with the recommendation
- Use "Choose X if... Choose Y if..." format
- Be decisive (avoid "it depends" as the main answer)
- Include clear winner if there is one

**Example:**
> **Quick Verdict:** Notion wins for teams who need collaboration and databases. Obsidian wins for individuals who want privacy and local control.
>
> **Choose Notion if:** You work with a team, need databases, want an all-in-one workspace
> **Choose Obsidian if:** You want local files, extensive linking, full ownership of your data

### Comparison Table
**Goal:** At-a-glance decision support.

**Include:**
- 8-12 differentiating features
- "Best For" row first
- Pricing row
- Clear ratings (numbers or checkmarks)
- Keep cells concise (1-3 words when possible)

### Individual Reviews
**Goal:** Comprehensive coverage of each option.

**Structure (for each):**
1. **What Makes It Different** - Unique positioning (2-3 sentences)
2. **Key Features** - 3-5 most important features
3. **Pros** - 3-5 advantages
4. **Cons** - 2-3 honest drawbacks (builds trust)
5. **Pricing** - Full breakdown
6. **Best For** - Specific user types and use cases
7. **Our Experience** - Personal usage if available

### Head-to-Head Scenarios
**Goal:** Help readers find themselves.

**Format:**
- Name specific scenarios readers identify with
- Declare a winner for each
- Explain why in 1-2 sentences
- Cover 4-6 scenarios

**Example scenarios:**
- For beginners
- For power users
- For teams
- For budget-conscious users
- For specific use case X
- For specific use case Y

### FAQ
**Goal:** Capture long-tail queries.

**Common questions:**
- Migration/switching questions
- Value/pricing questions
- Specific feature comparisons
- PAA questions from research

### Recommendation
**Goal:** Clear, actionable conclusion.

**Include:**
- Restate the winner/recommendation
- Who should choose which
- Specific next step (link, trial, etc.)

## Checklist Before Submission

```
Content Quality:
[ ] Quick verdict in first 300 words
[ ] Comparison table with 8+ features
[ ] Both options covered equally
[ ] Honest cons listed (not just pros)
[ ] Specific scenarios with clear winners
[ ] Personal experience or testing mentioned

SEO:
[ ] "vs" or "versus" in title
[ ] Comparison table present (Featured Snippet)
[ ] Both product names in first 100 words
[ ] FAQ section with common decision questions

Voice:
[ ] Takes a clear position
[ ] Specific recommendations, not vague
[ ] Honest about limitations of both
[ ] Reads like a trusted friend's advice
```
