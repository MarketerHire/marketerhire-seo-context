## Section Guidelines

### What You'll Achieve
**Goal:** Set expectations and confirm the reader is in the right place.

**Include:**
- Clear description of the end result
- Screenshot or example if possible
- Realistic time estimate
- List of what you'll need before starting
- Skill level required

**Example:**
> By the end of this tutorial, you'll have a fully configured Google Analytics 4 property tracking conversions on your website.
>
> **Time:** 15-20 minutes
> **What you'll need:** Google account, admin access to your website
> **Difficulty:** Beginner-friendly

### Why This Method
**Goal:** Build confidence that this is the right approach.

**Include:**
- Brief context (why this matters)
- Comparison to alternatives (optional)
- Clear statement of when this method works best
- Honest statement of when to use something else

### Step-by-Step Instructions
**Goal:** Zero-friction execution.

**Rules:**
1. **One action per step** - Don't combine multiple actions
2. **Number everything** - Steps, substeps, all numbered
3. **Show, don't just tell** - Screenshots, code examples, outputs
4. **Include checkpoints** - "At this point, you should see..."
5. **Inline troubleshooting** - "If you see X instead, try Y"

**Step Format:**
```
### Step N: [Action-Oriented Title]

[1-2 sentence overview of what this step accomplishes]

1. [First action]
2. [Second action]
3. [Third action]

**What you should see:** [Expected outcome]

**If something went wrong:** [Quick fix]
```

### Variations and Advanced Tips
**Goal:** Serve power users without confusing beginners.

**Include:**
- Alternative approaches for different situations
- Shortcuts or efficiency tips
- Customization options
- "Level up" suggestions

### Common Mistakes
**Goal:** Preempt problems and build trust.

**Format:**
- Name the mistake clearly
- Explain what happens when you make it
- Give the fix
- Share warning signs to watch for

### What's Next
**Goal:** Keep momentum and drive further engagement.

**Include:**
- Immediate next step (what to do right after)
- Related tutorials (if applicable)
- Resources for deeper learning
- Clear CTA

## Checklist Before Submission

```
Content Quality:
[ ] End result clearly described upfront
[ ] Time estimate is realistic
[ ] Prerequisites listed
[ ] Each step has ONE clear action
[ ] Checkpoints included at key moments
[ ] Troubleshooting tips inline
[ ] At least 3 common mistakes covered

SEO:
[ ] "How to" in title and H1
[ ] Steps are numbered (for Featured Snippet)
[ ] Primary keyword in first 100 words
[ ] FAQ potential in "Common Mistakes" section

Voice:
[ ] Instructions are direct (imperative mood)
[ ] No unnecessary hedging
[ ] Specific and concrete (not vague)
[ ] Friendly but efficient tone
```
